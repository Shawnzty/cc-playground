# AI Text-Image Adventure Game - Changelog

## Project Overview

An interactive text-based adventure game with AI-generated story content and images. Players make choices that shape the narrative, with each step featuring dynamically generated text and visuals.

## Tech Stack

- **Frontend**: React + Vite, deployed on Vercel
- **Backend**: Node.js + Express, deployed on Railway
- **AI Services**: OpenAI API
  - Text Generation: `gpt-4o-mini` (cost-optimized)
  - Image Generation: `DALL-E 2` at 512x512 (cost-optimized)

## Features

### Core Gameplay
- Step-by-step interactive storytelling
- 3 AI-generated choices per step
- Custom choice input - players can write their own actions
- AI-generated images for each scene
- Configurable story length: ~10, ~20 (default), 30-50, 50-100, or unlimited steps

### Onboarding Flow
1. **Language Selection**: English, Chinese, Spanish, French, German, Japanese, Korean
2. **Genre Selection**: Fantasy, Sci-Fi, Mystery, Romance, Horror, Adventure
3. **Tone Selection**: Lighthearted, Dramatic, Dark, Humorous
4. **Story Length**: Multiple options from short to unlimited
5. **Custom Theme**: Optional text input for specific settings/themes

### UI/UX Features
- **Multi-language Support**: Full UI localization in 7 languages
- **Compact Mobile UI**: Optimized padding and spacing for mobile devices
- **Clickable Title**: Returns to onboarding/restart
- **Step Rollback**: Click step number to see history menu with AI-generated summaries
- **Typing Animation**: Story text reveals character-by-character
- **Skeleton UI**: Placeholder boxes with shimmer effect during loading
- **Quill Loader**: Animated quill pen writing animation while waiting
- **Skip Animation**: Tap text area to skip typing animation

### Technical Features
- Session-based game state management
- In-memory storage (architecture ready for database)
- Structured JSON responses from AI
- Error handling and loading states

## Deployment

### Vercel (Frontend)
- Root directory: `client`
- Build command: `npm run build`
- Output directory: `dist`
- Environment variable: `VITE_API_URL` = Railway backend URL + `/api/game`

### Railway (Backend)
- Root directory: `server`
- Start command: `npm start`
- Port: 8080
- Environment variable: `OPENAI_API_KEY`

## Architecture Notes

### Session Management
Games are stored in-memory using a Map with session IDs. Each session contains:
- `preferences`: User's onboarding choices
- `history`: Array of story steps with responses and choices
- `currentStep`: Current position in story
- `maxSteps`: Story length limit

### API Endpoints
- `POST /api/game/start` - Start new game with preferences
- `POST /api/game/choose` - Make a choice (A, B, or C)
- `POST /api/game/custom-choice` - Submit custom action
- `POST /api/game/rollback` - Go back to previous step
- `GET /api/game/:sessionId/history` - Get step history for rollback menu

### AI Response Format
```json
{
  "storyText": "Narrative paragraph in selected language",
  "summary": "One-line summary (max 60 chars)",
  "imagePrompt": "Image description in English",
  "choices": [
    {"id": "A", "text": "First choice"},
    {"id": "B", "text": "Second choice"},
    {"id": "C", "text": "Third choice"}
  ]
}
```
